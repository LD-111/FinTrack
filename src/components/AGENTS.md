# components

- `layout/SplashScreen.tsx` — launch overlay: logo and wordmark on the sidebar color. App keeps it up until hydrate and a short minimum, then fades it out. No finance logic.
- `layout/Sidebar.tsx` — view switch, account list + inline create (includes Crypto/Stock), month net, keys 1/2/3. Portfolio accounts open Dashboard → Portfolio; other accounts open Ledger. Export and Import sit above the month net. **Manage accounts** sits under the list and is the only archive, restore, and delete entry. Delete asks for confirmation and lists transactions, transfers, valuation logs, and balance changes on other accounts. The create-account name field lists up to four similar accounts: Restore puts an archived one back and closes the form; choosing an active one opens it. An exact archived name makes Restore the primary button, with “Create a new one anyway” secondary. An exact active name disables Add.
- `transactions/QuickAddBar.tsx` — always visible formula bar; never hide behind a modal. A `+` amount on a spending category shows a Refund chip (including after arrowing the category chip).
- `transactions/TransactionTable.tsx` — dense ledger, account + category filters, inline edit, delete + undo. Changing the category keeps the cash direction. Rows are windowed; assert a row after scrolling it into view. Escape cancels an inline edit.
- `dashboard/DashboardView.tsx` + `VisualInsights.tsx` — Cashflow | Portfolio toggle. Cashflow: month stats, account balances, Recharts. Portfolio: `PortfolioPanel.tsx` (account chips, P/L, invested-vs-value chart, log value, history).
- `budgets/BudgetView.tsx` — monthly per-category caps; persist on Enter and blur (do not rely on unmount blur). Spent is net of refunds and may be negative; the progress bar stays at zero when spent is not positive.
- `ui/` — shadcn-style primitives (button, input, table, tooltip, card, badge, progress). Toasts use `src/lib/toast.ts` + `ui/sonner.tsx`.

Keyboard: Enter commits Quick Add, Tab cycles category/account/date chips, Esc clears the bar. `/` or Ctrl+K focuses the bar. Ctrl+Z undoes the ledger when focus is not in an input, textarea, or select; in a field it edits the text. `#account` targets an account. `500 #cash` with no description starts a transfer and suggests the other account; Tab to that chip and arrows change the destination. `500 #cash -> #savings` still logs an explicit transfer. Chip overrides (category, account, destination, date) commit as ids on the one Quick Add write, including `@Other income` and a date moved with the arrows. A `#token` that misses active accounts and matches one archived account previews `{name} is archived` and does not unarchive. Portfolio value log is a single input on the Portfolio tab (Enter / Log button). `1` / `2` / `3` are ignored while Quick Add (or any field) is focused, and while Manage accounts is open — Escape first when driving the UI from the keyboard. Escape closes Manage accounts. Setting the bar's DOM value does not render preview chips; type through React `onChange`. `body` does not scroll; screenshot or assert inside the scrolling `<main>` pane, and wait for `.recharts-surface` on Cashflow/Portfolio.
